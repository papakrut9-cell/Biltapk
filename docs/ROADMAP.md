# Bonsai Studio — Roadmap

План развития приложения (тернарные GGUF-модели PTQ1_0 / PQ2_0 / PQ2_0m, движок `com.arm.aichat`).
Актуально на версии 1.2.9 (versionCode 12).

## Статус

- ✅ Фиксы запуска и краш-логгер (1.2.2–1.2.4)
- ✅ Room v2 (история чата), ListAdapter/DiffUtil, ModelAdapter, время сообщений, длительность размышлений (1.2.5–1.2.6)
- ✅ Джни-бэкенды: `useLegacyPackaging`, стриминг токенов (1.2.5)
- ✅ Foreground-фиксы генерации: NonCancellable teardown, Stop, выгрузка модели, HTML-canvas (1.2.6)
- ✅ Полное отключение thinking на уровне промпта (1.2.7)
- ✅ Шторка размышлений: устойчивый парсинг think-блока (1.2.8)
- ✅ Thinking v3: jinja-kwargs `enable_thinking` (механизм PocketPal / llama.cpp server), синтез открывающего think-тега в «Вкл», защита от дублей тегов (1.2.9)

## Топ-приоритет

1. **Foreground service на время генерации** — сейчас сворачивание приложения во время ответа теряет генерацию. Нужен persistent-уведомление со стримом и кнопкой Stop, генерация живёт в фоне.
2. **Менеджер загрузки моделей** — поиск по Hugging Face, прогресс-бар, докачка после обрыва, список загруженных с занятым местом (референс: PocketPal). Снимает ручное копирование моделей.
3. **Настройки генерации** — температура, top-p, длина контекста, число потоков. Sample-параметры уже есть в llama.cpp-движке, нужен только UI-экран.

## Средний приоритет

4. **Обработка переполнения контекста** — индикатор «контекст полон», обрезка старых сообщений с сохранением system prompt. Особенно важно с thinking: размышления быстро съедают контекст.
5. **Разделение reasoning на уровне движка** — отдельный канал `reasoning_content` (как у llama.cpp server) вместо парсинга тегов в Kotlin; шторка работает без think-тегов вообще. Требует переработки `ai_chat.cpp` + JNI.
6. **Несколько чатов + редактируемый system prompt** — Room v2 почти готов принять.
7. **Счётчик токенов/сек** — бенчмарк квантований PTQ1_0 vs PQ2_0 / PQ2_0m прямо в приложении, сравнение на разном железе.

## Косметика (потом)

- **Minify release + ABI splits** — APK ~60 МБ → ~15–20 МБ; делать после стабилизации (риск обфускационных крашей).
- **Подсветка синтаксиса в canvas** — highlight.js в WebView (сейчас код рендерится plain text).
- **Material You / динамические цвета, splash screen.**

## Следующий шаг

Взять связку **1 + 3** (foreground service + настройки генерации): максимум пользы при ежедневном использовании. Менеджер загрузок (2) — следующий крупный этап, отдельный мини-проект (HF API, хранилище, права).

## Инфраструктура

- После каждого зелёного билда APK из артефакта CI **Bonsai-Studio-New** прикладывается к релизу вручную (права на release у интеграции недоступны).
- Патч `project/patches/ai_chat_thinking.patch` контекстно привязан к текущей prism-ветке `PrismML-Eng/llama.cpp` — при обновлении upstream перегенерировать: клон prism → правка `ai_chat.cpp` → `git diff` → `git apply --check` на свежем клоне.
- Сборка эмулятора: только загрузка модели (TCG без F16C → SIGABRT в ConvertF32F16); стриминг проверять на реальном ARM-устройстве.
